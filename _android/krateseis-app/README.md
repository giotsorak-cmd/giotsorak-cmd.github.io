# Κρατήσεις — εφαρμογή Android

Το APK ανοίγει τη σελίδα https://comfystay.gr/krateseis/ (φάκελος `krateseis/` αυτού του repo).
Αλλαγές στη σελίδα φτάνουν στο κινητό χωρίς νέο APK.

Σύνδεση με τον ίδιο λογαριασμό Firebase με το Ημερολόγιο Καταλυμάτων.
Οι κρατήσεις αποθηκεύονται στο `users/{uid}/krateseis` (ιδιωτικά για κάθε λογαριασμό).

## Build
Android Studio → Open → αυτός ο φάκελος → Build → Build App Bundle(s) / APK(s) → Build APK(s).
Το APK βγαίνει στο `app/build/outputs/apk/debug/app-debug.apk`.

Ο φάκελος ξεκινά με `_` ώστε το GitHub Pages να μην τον δημοσιεύει.
